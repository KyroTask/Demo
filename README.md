## 📖 About

This repo is the **standalone interactive demo** for [KyroTask](https://github.com/KyroTask/KyroTask) — a premium productivity platform built for Telegram. The demo runs entirely in the browser with pre-seeded mock data — no backend, no login required.

It's deployed automatically to **GitHub Pages** on every push to `main`.

---

## ✨ What You Can Explore

| Page | Description |
|------|-------------|
| 🏠 **Dashboard** | Overview of tasks, projects, Pomodoro level & recent activity |
| ✅ **Tasks** | Full task list with priorities, due dates & completion |
| 📁 **Projects** | Project board with progress tracking and milestones |
| 🎯 **Goals** | Goal tracking with sub-goals and progress bars |
| 🔥 **Habits** | Daily habit streaks and consistency tracking |
| ⏱️ **Pomodoro** | Deep-focus timer with XP leveling system |
| 📅 **Calendar** | Task & deadline calendar view |
| 📊 **Analytics** | Focus time charts, completion rates, habit stats |
| ⚙️ **Settings** | Theme toggle (light/dark), preferences |

---

## 🛠 Tech Stack

- **Vue 3** — Composition API
- **Vite 7** — Lightning-fast build tool
- **Tailwind CSS 3** — Utility-first styling
- **Pinia** — State management
- **Vue Router 4** — Client-side routing
- **GitHub Actions** — CI/CD auto-deploy to GitHub Pages

---

## 🚀 Run Locally

```bash
git clone https://github.com/KyroTask/demo.git
cd demo/app
npm install
npm run dev
```

> App runs at `http://localhost:5173`
